# Decisions

- **Container plus nested app repos:** mirrors the owner's Moonlight Peaks / Farm Together 2 model. Root tracks device docs/scripts/index; apps/ is ignored. Work on an app means its innermost repo. HelloCrown is durable in the main checkout by explicit owner exception; root changes stay in device-kit. No skills folder or submodule.
- **Toolchain:** use already-cached Gradle 8.13, AGP 8.13.2 and Kotlin 2.3.21 with installed JDK 21; Java/Kotlin target 17. Compile/target 36 uses the installed platform and build-tools 35.0.0, explicitly pinned. Build verification is the local compatibility evidence; future apps must inspect their own requirements. No SDK component downloads.
- **Platform UI:** standard Android Views avoid a larger UI dependency stack on 2 GB RAM. Landscape immersive mode fits the 1280x800 panel. No network permission, GMS or native libraries. minSdk 24 and ARMv7 filter are scaffold defaults.
- **Probe evidence:** AudioRecord produces raw PCM for host RMS checks; camera JPEG is decoded and checked for non-black pixels. These establish signal/capture feasibility, not subjective quality. Tone success requires owner audible confirmation. Legacy Camera API is intentional for this API-30 device and bounded sample, not a general production camera architecture.
- **Safety:** paired TLS discovery and verified serial selection; no reboot/remount/partition writes. Bluetooth inspection is read-only; no enabling/scan/pairing changes without a concrete supported reversible path. Elevated access remains explicitly untested. Two short monitor samples are not a soak claim.
- **Logs:** verbatim owner-run 1.0.0 template plus device-specific extension for timestamp-first filenames and bounded binary-safe ADB. Commands allowlist inventory; radio identities are filtered/redacted before persistence. Pairing is interactive and never logged.
- **Public repo, local device config (2026-11-12):** the root repo is public, so the device serial and optional ADB path live in git-ignored `config/device.local.json` (placeholder template `config/device.example.json`), read by `Get-DeviceConfig` in `device-session.ps1`. Rejected: env vars (harder to discover, per-shell) and a `-Serial` parameter on every script. The fast gate fails if tracked files contain the local serial or a private LAN address. Tests use fake values.
